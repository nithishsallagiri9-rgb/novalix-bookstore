A full-stack e-commerce web application for browsing and purchasing books online.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Python (Flask)
- **Database:** SQL / MySQL

## 📄 Pages
- `index.html` — Home page
- `books.html` — Book catalog/listing
- `bookdetail.html` — Individual book detail
- `login.html` / `signup.html` — User authentication
- `cart.html` — Shopping cart
- `checkout.html` — Order checkout
- `orders.html` — Order tracking
- `admin.html` — Admin panel

## ✨ Features
- User registration, login, and password reset
- Book catalog with browsing and search
- Shopping cart and checkout flow
- Order management and tracking
- Admin panel for managing books/orders
- Responsive design for all screen sizes

## 🚀 How to Run Locally
1. Clone the repo
   git clone https://github.com/YOUR_USERNAME/novalix-bookstore
2. Install Flask
   pip install flask
3. Run the backend
   python app.py
4. Open index.html in your browser
